## ✨ Overview

Sonpari-AI is a companion bot built for relaxed, everyday conversations in Hinglish. It supports:

| Capability | Description |
| :-- | :-- |
| 💬 **Conversations** | Casual, preference-aware chat with a friendly, non-romantic persona |
| 🔒 **Privacy controls** | User-controlled data settings, with message logging off by default |
| ⏰ **Reminders** | Set-and-forget reminders for daily life |
| 🌤️ **Mood check-ins** | Lightweight mood tracking between conversations |
| 🏆 **Daily challenges** | Small, repeatable prompts to keep things engaging |
| 🧠 **Quizzes** | Fun knowledge checks |
| 📴 **Local response logic** | Offline-friendly conversation engine |

> **A note on "offline":** Sonpari-AI still requires Telegram's Bot API to communicate with Telegram. The conversation engine is designed to run locally — but review the optional modules and deployment configuration before describing the whole application as fully offline.

## 🚀 Quick Start

**Prerequisites:** Python 3.11 or newer.

1. **Configure environment**
   ```bash
   cp .env.example .env
   ```
2. **Set your bot token** — create one via Telegram's official [@BotFather](https://t.me/BotFather), then add it to `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=your_token_here
   ```
3. **Set the owner ID** — your numeric Telegram user ID:
   ```env
   OWNER_ID=123456789
   ```
4. **Install dependencies**
   ```bash
   python -m pip install -r requirements.txt
   ```
5. **Run the bot**
   ```bash
   python run.py
   ```

> 🚫 **Never commit** `.env`, database files, logs, backups, or real user data.

### Configuration reference

| Variable | Required | Description |
| :-- | :--: | :-- |
| `TELEGRAM_BOT_TOKEN` | ✅ | Token generated by Telegram's BotFather |
| `OWNER_ID` | ✅ | Numeric Telegram user ID of the bot owner |

## 🔐 Data & Privacy

Sonpari-AI is designed with privacy as a default, not an afterthought.

- **No bundled data** — runtime databases and conversation-learning files are intentionally excluded from this repository.
- **Logging off by default** — message-content logging is disabled unless explicitly enabled.
- **Review before deploying** — read [`docs/PRIVACY.md`](docs/PRIVACY.md) and the implementation before putting this in front of real users.
- **Credential hygiene** — rotate any credential that has ever appeared in a shared archive or public repository.
